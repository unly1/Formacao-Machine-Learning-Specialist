CONCEITO:
  A Lógica Fuzzy (nebulosa) permite trabalhar com graus de
  pertinência entre 0 e 1, modelando incerteza e linguagem
  natural de forma matemática.

PIPELINE DO SISTEMA:
  [Entrada Crisp] → [Fuzzificação] → [Base de Regras]
                 → [Defuzzificação] → [Saída Crisp]

FUNÇÕES DE PERTINÊNCIA UTILIZADAS:
  • Triangular  : pertinencia_triangular(x, a, b, c)
  • Trapezoidal : pertinencia_trapezoid(x, a, b, c, d)
  • Gaussiana   : pertinencia_gaussiana(x, media, sigma)

CONJUNTOS FUZZY - TEMPERATURA (Entrada):
  • FRIA        : Trapezoidal [0, 0, 15, 25]
  • CONFORTÁVEL : Triangular  [15, 22, 30]
  • QUENTE      : Trapezoidal [25, 32, 50, 50]

BASE DE REGRAS (SE-ENTÃO):
  • SE temp é FRIA        → Ventilador LENTO  (centro: 20%)
  • SE temp é CONFORTÁVEL → Ventilador MÉDIO  (centro: 50%)
  • SE temp é QUENTE      → Ventilador RÁPIDO (centro: 90%)

DEFUZZIFICAÇÃO: Método do Centroide (Center of Gravity)
  Fórmula: saída = Σ(μᵢ × cᵢ) / Σ(μᵢ)

  VANTAGENS DA LÓGICA FUZZY EM MACHINE LEARNING:
==============================================================
  1. Lida com incerteza e imprecisão de forma natural
  2. Regras interpretáveis (linguagem humana)
  3. Não requer grande volume de dados rotulados
  4. Base para sistemas híbridos (Neuro-Fuzzy, ANFIS)
  5. Útil em controle, classificação e tomada de decisão

  APLICAÇÕES COMUNS:
  • Controle industrial (temperatura, velocidade, pressão)
  • Sistemas de recomendação
  • Diagnóstico médico assistido
  • Processamento de linguagem natural
  • Robótica e veículos autônomos
