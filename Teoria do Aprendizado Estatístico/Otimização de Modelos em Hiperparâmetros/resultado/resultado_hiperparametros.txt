O QUE SÃO HIPERPARÂMETROS?
  São configurações definidas ANTES do treinamento. Diferente
  dos parâmetros (pesos), eles não são aprendidos pelo modelo.

HIPERPARÂMETROS DE ARQUITETURA (estrutura da rede):
  • num_layers    : número de camadas ocultas
  • neurons       : neurônios por camada
  • activation    : função de ativação (ReLU, Tanh, Sigmoid)

HIPERPARÂMETROS DE TREINAMENTO (processo de aprendizado):
  • learning_rate : tamanho do passo no gradiente descendente
  • batch_size    : amostras por atualização de peso
  • epochs        : número de ciclos completos sobre o dataset
  • optimizer     : algoritmo de otimização (SGD, Adam, RMSProp)

HIPERPARÂMETROS DE REGULARIZAÇÃO (combate ao overfitting):
  • dropout_rate  : fração de neurônios desativados por época

ESPAÇO DE BUSCA DEFINIDO:
  • learning_rate     : [0.1, 0.01, 0.001, 0.0001]
  • epochs            : [10, 30, 50]
  • batch_size        : [16, 32, 64]
  • neurons           : [32, 64, 128]
  • dropout_rate      : [0.0, 0.2, 0.5]
  • activation        : ['relu', 'tanh', 'sigmoid']
  • optimizer         : ['sgd', 'adam', 'rmsprop']
  • num_layers        : [1, 2, 3]

=================================================================
  ESTRATÉGIAS DE BUSCA DE HIPERPARÂMETROS
=================================================================

1. GRID SEARCH (Busca em Grade)
   Testa sistematicamente todas as combinações.
   Vantagem : garante encontrar o melhor no espaço definido.
   Desvantagem: custo computacional exponencial (maldição
   da dimensionalidade).

2. RANDOM SEARCH (Busca Aleatória)
   Amostra aleatoriamente o espaço de configurações.
   Vantagem : eficiente — cobre bem espaços grandes.
   Referência: Bergstra & Bengio (2012) mostraram que
   Random Search supera Grid Search na maioria dos casos.

3. BAYESIAN OPTIMIZATION (referência teórica)
   Usa modelo probabilístico (ex: Gaussian Process) para
   guiar a busca. Implementações: Optuna, Hyperopt, KerasTuner.

4. EARLY STOPPING
   Interrompe o treino quando a val_loss para de melhorar.
   Evita overfitting e economiza tempo de computação.

=================================================================
  BOAS PRÁTICAS DE AJUSTE DE HIPERPARÂMETROS
=================================================================

  LEARNING RATE:
  • É o hiperparâmetro mais crítico em Deep Learning
  • Comece com 1e-3 (Adam) ou 1e-2 (SGD)
  • Use Learning Rate Scheduler (ex: ReduceLROnPlateau)
  • Visualize a curva de loss: se oscilar, reduza o LR

  BATCH SIZE:
  • Lotes menores (16-32): mais ruído, melhor generalização
  • Lotes maiores (128+) : mais estável, mais rápido por época
  • Regra prática: comece com 32

  DROPOUT:
  • Use 0.2–0.5 nas camadas ocultas para regularização
  • Nunca aplique na camada de saída
  • Combine com Batch Normalization para melhor resultado

  ARQUITETURA:
  • Comece simples (1-2 camadas) e aumente a complexidade
  • ReLU é a ativação padrão para camadas ocultas
  • Mais neurônios e camadas = mais capacidade e mais risco

  OTIMIZADORES:
  • Adam    : melhor ponto de partida (adaptativo)
  • RMSProp : bom para RNNs e dados ruidosos
  • SGD     : pode superar Adam com LR scheduler afinado

  FERRAMENTAS RECOMENDADAS PARA PRODUÇÃO:
  • Optuna      : Bayesian Optimization automático
  • KerasTuner  : integrado ao TensorFlow/Keras
  • Ray Tune    : busca distribuída em cluster
  • Weights & Biases (wandb): rastreamento de experimentos
