# Conhecendo as Bibliotecas Pandas e Scikit-Learn

Este módulo apresenta uma abordagem teórica focada nas bibliotecas Pandas e Scikit-Learn, utilizadas para a manipulação, análise de dados e construção de modelos de aprendizado de máquina em Python.

## Conteúdo Teórico

O conteúdo desta pasta é predominantemente teórico e abrange os seguintes tópicos fundamentais:

1. **Biblioteca Pandas**
   - Introdução à biblioteca e sua importância na análise de dados.
   - Estruturas de dados fundamentais (Series e DataFrames).

2. **Biblioteca Pandas e suas funções**
   - Principais operações para importação, limpeza, transformação e filtragem de dados.
   - Exploração de dados através de agrupamentos, junções e manipulação de índices.

3. **Biblioteca Scikit-learn**
   - Visão geral do framework padrão para Machine Learning em Python.
   - Ciclo de vida de modelagem: pré-processamento, separação de dados, treinamento de modelos de classificação/regressão e métricas de avaliação.
