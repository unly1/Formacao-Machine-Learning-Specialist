# Desenvolvimento de Algoritmos no Keras

Este módulo apresenta uma abordagem teórica e prática focada no desenvolvimento de algoritmos utilizando a biblioteca Keras, uma API de redes neurais de alto nível executada sobre o TensorFlow.

## Conteúdo Teórico

O conteúdo principal abrange o seguinte tópico fundamental:

1. **Introdução ao Keras**
   - Histórico e evolução da biblioteca Keras e sua integração nativa com o ecossistema TensorFlow.
   - Entendimento das principais abstrações (como modelos Sequenciais, API Funcional, camadas, otimizadores e funções de perda) para estruturação de redes neurais.
   - Vantagens do Keras como uma API amigável e modular para prototipagem rápida de modelos de Deep Learning.
